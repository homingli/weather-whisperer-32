## Research answer

**Yes, free sources exist for HK rain prediction beyond your current HKO nowcast (0–2h):**

1. **Open-Meteo (already integrated)** — best option. Verified live: `minutely_15=precipitation` works for HK (15-min steps, ~3 days) plus hourly `precipitation`/`precipitation_probability` to 16 days. Aggregates the US/EU institutions you asked about (NOAA GFS, ECMWF IFS/AIFS, DWD ICON, Météo-France, UKMO), selectable per request. Free non-commercial, no key, CORS-friendly. **Granularity caveat (verified live): it snaps to ~7–8 km grid cells — Kwun Tong and Central return identical series. City-scale, not district-scale; only the HKO ~1 km nowcast grid (0–2h) is district-precise.**
2. **MET Norway locationforecast 2.0** — free CC license, no key (User-Agent required), ECMWF-based for HK; backup option, has redistribution restrictions.
3. **ECMWF Open Data / NOAA GFS raw** — free (CC-BY-4.0) but GRIB2 via AWS/NOMADS; needs a backend, not browser-viable. Open-Meteo is their practical wrapper.
4. **Not recommended:** Google Weather API (GCP key + billing), OpenWeatherMap minutely (often empty for HK, needs key), RainViewer (personal-use, ~30–60 min tiles, reported discontinuation ~Jan 2026, redundant vs HKO).

**Conclusion:** HKO nowcast (0–2h, district-precise) + Open-Meteo (2–24h+, city-scale) — the latter is one extra parameter on an existing call.
